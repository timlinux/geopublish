# geopublish

A reproducible, Nix-provisioned workflow for publishing vector and raster
geospatial data to PostgreSQL/PostGIS, and viewing it in QGIS.

See the [user guide](user/index.md) to get started, the
[administrator guide](admin/index.md) for database setup, or the
[developer guide](developer/index.md) to extend the CLI.
